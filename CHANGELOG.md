# Changelog

## 0.1.1

- Allow compatible glam 0.32 patch releases instead of forcing 0.32.0. Verified with glam 0.32.1 and Bevy 0.19.1; no solver or animation algorithm changes.

## 0.1.0 (2026-10-09)

- Scalar dampers, exact springs, composite springs, all nine tracking variants and prediction.
- Inertialization, dead blending and easing.
- Generic scalar/vector forms and quaternion springs, with glam optional.
- Bevy 0.19.1 plugin with virtual/manual clocks, transform springs and generic values.
- Executable C++ reference fixtures, behavioral tests, examples and provenance.

- MIT distribution with upstream notices preserved; original additions dedicated under CC0.
- Claude credited for design, Codex for implementation and verification.

Release authorized after minimal Bevy integration verification.
